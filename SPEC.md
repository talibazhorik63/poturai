# Специфікація проекту (SPEC): Лендінг бренду термосів "ThermoPeak"

## 1. Загальний огляд проекту
- **Назва проекту:** Лендінг "ThermoPeak"
- **Цільова аудиторія:** Студенти-початківці, які починають вивчати HTML та CSS
- **Тематика:** Виробництво та продаж термосів / термопосуду (тема подорожей та активного відпочинку)
- **Технологічний стек:** HTML5 та CSS3 (використання 3 способів підключення стилів та 3 типів стилів у `style.css`)
- **Концепція дизайну:** Сучасний, адаптивний лендінг із 3 варіантами оформлення (тем дизайну) на вибір користувача.

---

## 2. Навчальні цілі (що практикують студенти)
Студенти при створенні сторінки ознайомляться та закріплять:
1. Базову структуру HTML-документа (`<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<body>`).
2. Ієрархію заголовків (`<h1>`, `<h2>`, `<h3>`).
3. Роботу з параграфами тексту (`<p>`).
4. Теги форматування тексту (`<strong>`, `<b>`, `<em>`, `<i>`, `<small>`, `<br>`, `<hr>`).
5. Вставку зображення та роботу з його атрибутами (`<img src="..." alt="..." width="...">`).
6. **Основи та 3 способи підключення CSS**:
   - **Зовнішні стилі (External CSS):** створення файлу `style.css` та підключення через тег `<link rel="stylesheet" href="style.css">`.
   - **Внутрішні стилі (Internal CSS):** написання CSS-правил всередині тегу `<style>` у секції `<head>`.
   - **Вбудовані / Інлайн стилі (Inline CSS):** застосування атрибута `style="..."` безпосередньо у тегах HTML.
7. **Створення та застосування 3 типів стилів (тем оформлення) у `style.css`**:
   - Використання CSS-змінних (`:root`, `body.theme-forest`, `body.theme-ocean`, `body.theme-dark`).

## 3. Структура сторінки та вимоги до вмісту

Сторінка будується за принципом простого послідовного відображення з інтерактивною панеллю вибору стилю.

### Розділ 1: Шапка сторінки (Header)
- **Панель перемикання 3 типів стилів:** Кнопки для швидкої зміни оформлення (`.theme-forest`, `.theme-ocean`, `.theme-dark`).
- **Головний заголовок першого рівня (`<h1>`):** `ThermoPeak`
- **Підзаголовок другого рівня (`<h2>`):** *Створено для пригод, збережено з ідеальною температурою.*
- **Горизонтальний розділювач (`<hr>`):** Стилізована розділювальна лінія.

### Розділ 2: Головний блок товару (Hero / Вступ)
- **Заголовок товару третього рівня (`<h3>`):** Представляємо **ThermoPeak Explorer 1000 мл**
- **Зображення товару (`<img>`):**
  - Фотографія термоса на фоні гір/природи.
  - Обов'язкові атрибути: `src`, `alt="Термос ThermoPeak Explorer з нержавіючої сталі"`, `width="400"`.
- **Вступний опис (`<p>`):**
  - Текстовий опис продукту з акцентними виділеннями.
- **Ключові характеристики:**
  - Оформлені карткою із використанням тегів `<b>`, `<i>`, `<strong>`, `<em>`.

### Розділ 3: Опис переваг та гарантія
- **Заголовок блоку (`<h3>`):** Чому обирають ThermoPeak?
- **Параграфи тексту (`<p>`):** Пояснення технологій, екологічності та міцності.

### Розділ 4: Підвал сторінки (Footer)
- **Примітка або копірайт (`<small>`):** Копірайт та слоган.

## 4. Опис 3 типів стилів (тем оформлення) у `style.css`

У файлі `style.css` реалізовано 3 універсальні типи стилів (колірні теми), які динамічно перемикаються за допомогою класифікації `body`:

1. **Тип 1: Еко-Зелений (Forest Green — `.theme-forest`):**
   - Тема природи та гірських лісів. Основний колір — насичений лісовий зелений (`#1e3f20`), акцентний колір — теплий бурштиновий (`#d97706`), світлий природний фон (`#f4f6f4`).

2. **Тип 2: Альпійський Синій (Alpine Blue — `.theme-ocean`):**
   - Тема океану та гірського льоду. Основний колір — океанічний синій (`#0f4c81`), акцентний колір — свіжий блакитний (`#0284c7`), холодний світло-сірий фон (`#f0f6fc`).

3. **Тип 3: Темний Дослідник (Dark Night — `.theme-dark`):**
   - Сучасна темна тема для нічних пригод. Основний колір — неоновий блакитний (`#38bdf8`), акцентний колір — золотисто-жовтий (`#f59e0b`), глибокий темний фон (`#0f172a`) та картка (`#1e293b`).

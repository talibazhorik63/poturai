# Специфікація проекту (SPEC): Лендінг бренду термосів "ThermoPeak"

## 1. Загальний огляд проекту
- **Назва проекту:** Лендінг "ThermoPeak"
- **Цільова аудиторія:** Студенти-початківці, які тільки починають вивчати основи HTML
- **Тематика:** Виробництво та продаж термосів / термопосуду (тема подорожей та активного відпочинку)
- **Технологічний стек:** Тільки чистий HTML5 (Без використання CSS та без JavaScript)
- **Концепція дизайну:** Семантична, зрозуміла та послідовна структура сторінки з читанням зверху вниз за допомогою базових тегів.

---

## 2. Навчальні цілі (що практикують студенти)
Студенти при створенні сторінки ознайомляться та закріплять:
1. Базову структуру HTML-документа (`<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<body>`).
2. Ієрархію заголовків (`<h1>`, `<h2>`, `<h3>`).
3. Роботу з параграфами тексту (`<p>`).
4. Теги форматування тексту:
   - Важливий та жирний текст (`<strong>`, `<b>`)
   - Текст із наголосом та курсив (`<em>`, `<i>`)
   - Дрібний текст для приміток (`<small>`)
5. Елементи розділення контенту (`<hr>`, `<br>`).
6. Вставку зображення та роботу з його атрибутами (`<img src="..." alt="..." width="...">`).

---

## 3. Структура сторінки та вимоги до вмісту

Сторінка будується за принципом простого послідовного відображення без складних навігаційних меню.

### Розділ 1: Шапка сторінки (Header)
- **Головний заголовок першого рівня (`<h1>`):** `ThermoPeak`
- **Підзаголовок другого рівня (`<h2>`):** *Створено для пригод, збережено з ідеальною температурою.*
- **Горизонтальний розділювач (`<hr>`):** Візуальна лінія для відокремлення брендового блоку.

### Розділ 2: Головний блок товару (Hero / Вступ)
- **Заголовок товару третього рівня (`<h3>`):** Представляємо **ThermoPeak Explorer 1000 мл**
- **Зображення товару (`<img>`):**
  - Фотографія термоса на фоні гір/природи.
  - Обов'язкові атрибути: `src`, `alt="Термос ThermoPeak Explorer у горах"`, `width="400"`.
- **Вступний опис (`<p>`):**
  - Текстовий опис продукту.
  - Приклад вмісту:
    > *"Підкорюєте гірські вершини чи їдете на роботу в морозний ранок — **ThermoPeak Explorer** збереже ваші напої <strong>гарячими до 24 годин</strong> або <em>крижаними до 48 годин</em>."*
- **Ключові характеристики (для практики форматування тексту):**
  - Перенесення рядків за допомогою `<br>`.
  - Використання тегів `<b>`, `<i>`, `<strong>`, `<em>`.
  - Приклад: `<b>Збереження тепла:</b> <i>24 години гаряче / 48 годин холодне</i>`
  - Приклад: `<strong>Матеріал:</strong> Харчова нержавіюча сталь 18/8 (без BPA)`

### Розділ 3: Опис переваг та гарантія
- **Заголовок блоку (`<h3>`):** Чому обирають ThermoPeak?
- **Параграфи тексту (`<p>`):**
  - Коротке пояснення технології подвійної вакуумної ізоляції.
  - Акцент на міцності, захисті від протікання та екологічності.
- **Горизонтальний розділювач (`<hr>`):** Розділення перед підвалом.

### Розділ 4: Підвал сторінки (Footer)
- **Примітка або копірайт (`<small>` або `<p>`):**
  - Авторські права: `&copy; 2026 ThermoPeak Outdoors Inc. Усі права захищено.`
  - Слоган: *Створено для дослідників, збудовано на віки.*

---

## 4. Технічні обмеження та правила
- **Тільки HTML:** Жодних тегів `<style>`, інлайн-стилів `style="..."`, файлів `.css` чи скриптів `<script>`.
- **Валідний семантичний HTML5:** Коректне закриття тегів і правильна вкладеність.
- **Простота:** Код повинен бути максимально простим і зрозумілим для студентів.

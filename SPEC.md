# Специфікація проекту (SPEC): Лендінг бренду термосів "ThermoPeak"

## 1. Загальний огляд проекту
- **Назва проекту:** Лендінг "ThermoPeak"
- **Цільова аудиторія:** Студенти-початківці, які починають вивчати HTML та CSS
- **Тематика:** Виробництво та продаж термосів / термопосуду (тема подорожей та активного відпочинку)
- **Технологічний стек:** HTML5 та CSS3 (стилізація через тег `<style>` всередині `<head>`)
- **Концепція дизайну:** Сучасний, адаптивний лендінг з виразним візуальним стилем (приємна колірна гама, тіні, м'які мікроанімації та зручне розташування елементів).

---

## 2. Навчальні цілі (що практикують студенти)
Студенти при створенні сторінки ознайомляться та закріплять:
1. Базову структуру HTML-документа (`<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<body>`).
2. Ієрархію заголовків (`<h1>`, `<h2>`, `<h3>`).
3. Роботу з параграфами тексту (`<p>`).
4. Теги форматування тексту (`<strong>`, `<b>`, `<em>`, `<i>`, `<small>`, `<br>`, `<hr>`).
5. Вставку зображення та роботу з його атрибутами (`<img src="..." alt="..." width="...">`).
6. **Основи CSS**:
   - Роботу з селекторами (теги, класи).
   - Оформлення тексту (сімейство шрифтів, розміри, висота рядка, колір).
   - Блочну модель (внутрішні `padding` та зовнішні `margin` відступи).
   - Flexbox або сітки для центрування вмісту та створення контейнерів.
   - Декорування (округлення кутів `border-radius`, тіні `box-shadow`, плавні переходи `transition`).

---

## 3. Структура сторінки та вимоги до вмісту

Сторінка будується за принципом простого послідовного відображення без складних навігаційних меню, але оформлена з використанням сучасного дизайну.

### Розділ 1: Шапка сторінки (Header)
- **Головний заголовок першого рівня (`<h1>`):** `ThermoPeak`
- **Підзаголовок другого рівня (`<h2>`):** *Створено для пригод, збережено з ідеальною температурою.*
- **Горизонтальний розділювач (`<hr>`):** Може бути стилізований або замінений на CSS-межі.

### Розділ 2: Головний блок товару (Hero / Вступ)
- **Заголовок товару третього рівня (`<h3>`):** Представляємо **ThermoPeak Explorer 1000 мл**
- **Зображення товару (`<img>`):**
  - Фотографія термоса на фоні гір/природи.
  - Обов'язкові атрибути: `src`, `alt="Термос ThermoPeak Explorer у горах"`, `width="400"`.
- **Вступний опис (`<p>`):**
  - Текстовий опис продукту.
- **Ключові характеристики:**
  - Оформлені списком або виділеними параграфами із використанням тегів `<b>`, `<i>`, `<strong>`, `<em>`.

### Розділ 3: Опис переваг та гарантія
- **Заголовок блоку (`<h3>`):** Чому обирають ThermoPeak?
- **Параграфи тексту (`<p>`):** Пояснення технологій, екологічності та міцності.

### Розділ 4: Підвал сторінки (Footer)
- **Примітка або копірайт (`<small>`):** Копірайт та слоган.

---

## 4. Технічні обмеження та правила
- **Вбудовані стилі:** CSS має знаходитися всередині тегу `<style>` у секції `<head>`.
- **Жодного зовнішнього JS:** Тільки статична розмітка та стилі.
- **Адаптивність:** Сторінка має привабливо виглядати як на мобільних пристроях, так і на десктопах.

---
